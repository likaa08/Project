# PetShelter — учёт животных в приюте

Windows Forms-приложение для просмотра питомцев по фильтрам, сохранения подборок в JSON/XML и редактирования состава приюта.

## Запуск

```bash
dotnet build PetShelter.slnx
dotnet run --project PetShelter
```

Требуется **.NET 9** (Windows).

При первом запуске создаются:
- данные приютов: `%LocalAppData%\PetShelter\shelters.json`;
- папка отчётов: `%LocalAppData%\PetShelter\Reports\`.

---

## Окна приложения

В программе **три окна**:

| Окно | Как открыть | Как закрыть |
|------|-------------|-------------|
| **Главное меню** | Запуск приложения | Крестик (×) — закрывается всё приложение |
| **Подборка питомцев** (таблица) | Кнопка «Показать питомцев» в главном меню | Крестик (×) — закрывается только это окно; главное меню остаётся |
| **Новый питомец** | Кнопка «Добавить» в окне таблицы | «OK» / «Отмена» или крестик |

Окно таблицы открывается **отдельно** от главного (не блокирует его): можно снова нажать «Показать питомцев» и открыть ещё одну таблицу с другими фильтрами.

## Главное меню

Заголовок окна: **«Приют для животных — главное меню»**.

### Список «Приют»

- Пункт **«(все приюты)»** — учитываются все приюты (с учётом других фильтров).
- Конкретное имя (**Солнечный**, **Тихий двор**, **Лесная поляна**) — только выбранный приют.
- Если выбран **«(все приюты)»**, в таблице при открытии в списке «Приют» подставится первый приют из списка (для добавления питомца).

### Список «Вид животного»

- **«(все виды)»** — показываются кошки, собаки, кролики и попугаи.
- **Cat**, **Dog**, **Rabbit**, **Parrot** — только выбранный тип.

### Галочка «Только приюты с открытой территорией»

- **Снята** — в выборку попадают все приюты (открытые и закрытые).
- **Включена** — остаются только приюты с открытой территорией (например, «Солнечный», «Лесная поляна»; «Тихий двор» скрывается).

### Галочка «Только с клаустрофобией»

- **Снята** — показываются все питомцы по остальным фильтрам.
- **Включена** — только животные с клаустрофобией (в закрытый приют таких не помещают).

### Список «Формат отчёта»

- **JSON** или **XML** — в каком формате сохраняется подборка при нажатии «Показать питомцев».
- При **смене формата** все уже сохранённые отчёты вида `Подборка_*` текущего формата копируются в файлы нового формата (в папке `Reports`).

### Кнопка «Показать питомцев»

1. Собирает питомцев по выбранным фильтрам.
2. Сохраняет файл подборки: `Подборка_№N_от_ДД.ММ.ГГГГ.json` или `.xml`.
3. Открывает окно **«Подборка питомцев»** с таблицей.

**Сообщение «Питомцев нет…»** появляется, если по фильтрам никого не найдено **и** нельзя определить один приют для добавления (выбраны «все приюты» и несколько приютов в фильтре). В этом случае выберите **один приют** в списке и нажмите кнопку снова — откроется пустая или частичная таблица, можно нажать **«Добавить»**.

## Окно «Подборка питомцев»

### Таблица

Столбцы:

| Столбец | Содержание |
|---------|------------|
| Вид | Кошка, Собака, Кролик, Попугай |
| Кличка | Имя питомца |
| Возраст | Лет |
| Вес, кг | Масса |
| Порода | Порода |
| Клаустрофобия | «да» / «нет» |
| Доп. поле | Окрас, дрессировка, длина ушей и т.д. |

Таблица только для просмотра (редактирование ячеек недоступно). Выделите **целую строку**, чтобы удалить питомца.

### Строка информации (внизу слева)

Показывает имя сохранённого файла подборки, число строк в таблице и (если выбран приют в списке) сколько питомцев всего в этом приюте.

### Список «Приют»

Выбор приюта, **в который** добавляется или **из которого** удаляется питомец. Список всегда активен.

### Кнопка «Добавить»

- **Всегда активна**, если в списке «Приют» есть выбранное значение.
- Открывает окно **«Новый питомец»**.
- После успешного добавления данные сохраняются в `shelters.json`, таблица обновляется.
- **Нельзя добавить**, если:
  - в приюте нет мест;
  - у питомца клаустрофобия, а приют **закрытый** (без открытой территории);
  - в этом приюте уже есть питомец с такой же кличкой и видом.

### Кнопка «Удалить»

- **Активна**, только когда в таблице **выделена строка**.
- Удаляет питомца из выбранного в списке приюта и из таблицы, сохраняет изменения в JSON.

## Окно «Новый питомец»

Открывается поверх окна таблицы (главное меню при этом остаётся на заднем плане).

| Поле | Назначение |
|------|------------|
| Вид | Cat / Dog / Rabbit / Parrot |
| Кличка | Обязательное поле |
| Возраст | Число 0–30 |
| Вес | В килограммах |
| Порода | Текст |
| Доп. 1 | У кошки — окрас; у собаки — уровень дрессировки; у кролика — длина ушей (см); у попугая — цвет оперения |
| Доп. 2 | Галочка (у кошки — любит коробки; у собаки — охранник; у кролика — высокие прыжки; у попугая — умеет говорить) |
| Клаустрофобия | Галочка — нельзя помещать в закрытый приют |

- **OK** — создать питомца и закрыть окно.
- **Отмена** или крестик — отмена без добавления.
